# Keyword Lab — Hermes

Sito informativo del progetto personale Hermes di Angelo Galanti.

- Home: https://hermes.webica.dev/
- Privacy: https://hermes.webica.dev/privacy.html

Solo HTML e CSS, senza dipendenze, JavaScript, tracciamento o moduli.
Pubblicazione con GitHub Pages dal branch `main`, cartella radice.

Non caricare credenziali OAuth, token, file di configurazione o risultati API
in questo repository pubblico. Gli script di ricerca restano separati.

La pubblicazione del sito non costituisce approvazione OAuth o accesso Basic
per Google Ads API. La verifica della proprietà e del brand è un passaggio
separato. Il dominio autorizzato in OAuth è `webica.dev`; la proprietà deve
essere verificata in Search Console con un account associato al progetto Cloud.

DNS richiesto: CNAME `hermes` → `angelogalanti.github.io`, modalità DNS only.
Il dominio è pronto solo dopo propagazione DNS ed emissione del certificato HTTPS.
